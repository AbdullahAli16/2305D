📘 Project: Library Management System
🎯 Objective

Build a console-based Library Management System using Python and Object-Oriented Programming concepts.

The system should allow users to:

Add books

View books

Issue books

Return books

Remove books

Save and load data from a file

📌 Requirements
1️⃣ Create a Book Class

Each book should have:

title

author

copies

Rules:

Copies cannot be negative.

Use encapsulation (private variable + property).

Implement a method to display book information.

Implement __str__() so book objects print nicely.

2️⃣ Create a Library Class

The library should:

Store books in a list.

Provide CRUD operations.

📌 Functional Requirements
🔹 1. Add Book

Create a method:

add_book(title, author, copies)


This should:

Create a new Book object

Add it to the library list

🔹 2. Show Books

Create a method:

show_books()


This should:

Loop through all books

Print each book’s details

If no books exist, show a message

🔹 3. Issue Book

Create a method:

issue_book(title)


This should:

Find book by title

If copies > 0 → decrease by 1

If copies == 0 → show “No copies available”

If book not found → show “Book not found”

🔹 4. Return Book

Create a method:

return_book(title)


This should:

Find book by title

Increase copies by 1

If book not found → show message

🔹 5. Remove Book (IMPORTANT)

Create a method:

remove_book(title)


This method must:

Search for a book by title.

If found:

Remove the book from the list.

Print “Book removed.”

Stop execution immediately using return.

If no book matches:

Print “Book not found.”

Important Rule:

You must remove the book safely while iterating.
Do not cause index errors.

🔹 6. Save Data to File

Create:

save_data()


This should:

Save all books into a text file

Format: title,author,copies

🔹 7. Load Data from File

Create:

load_data()


This should:

Read file data

Recreate book objects

Add them to library

📌 OOP Concepts You Must Use
Concept	Requirement
Encapsulation	Private variable + property
Inheritance	Create abstract base class LibraryItem
Abstraction	Use abc and @abstractmethod
Polymorphism	Override display method
Method overriding	Required
Dunder method	__str__()
📌 Menu System

Create a looped menu:

1. Add Book
2. Show Books
3. Issue Book
4. Return Book
5. Remove Book
6. Exit


The program should:

Keep running until user chooses Exit.

Save data before exiting.
